# Community v1.0 release checklist

- [ ] `npm test` passes
- [ ] Windows Actions build produces `BBX-Community-v1.0-Setup.exe`
- [ ] Install on fresh Windows 10 and 11 without preinstalled Node
- [ ] Browser opens automatically from shortcut
- [ ] Horizontal OBS 1920x1080 transparent output verified live
- [ ] Vertical OBS 1080x1920 transparent output verified live
- [ ] Scoring, undo, round and match win, judge calls, side swapping tested during a real match
- [ ] Settings persist after closing and relaunching
- [ ] Uninstall works and private match state remains in user profile
- [ ] Installer digitally signed and name/logo legal review completed
- [ ] License terms, support contact, privacy disclosure and public download page prepared

No private Spin Network user data, Player Portal, league network or OBS automation must be added to Community.
