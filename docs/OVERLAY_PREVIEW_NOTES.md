# Overlay preview notes

The v1.0.1 player-panel layout puts match data on the left and right, a points-only scorebug at center, and side-specific finish animations below the scoring player.

The examples are synthetic and not derived from any player database.

Real overlays are transparent. White shown in a standard browser screenshot is the browser page background and is not rendered over game footage in correctly configured OBS Browser Sources.

In OBS configure horizontal 1920 x 1080 or vertical 1080 x 1920. In a standalone browser, the stage now scales to fit the available viewport.
